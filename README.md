# Nord Bati Planning

Application de planning intelligent pour Nord Bati Construction.

## Fonctionnalités

- 📅 Vue "Aujourd'hui" - Qui fait quoi ce matin
- 📊 Planning équipes sur 2 semaines
- 🏗️ Gestion des chantiers avec lots multiples
- 👥 Gestion des équipes/binômes (26 salariés + 4 sous-traitants)
- 🚚 Planning livreur (Alex) séparé
- 🔔 Rappels automatiques (arrêtés voirie, Consuel, Qualigaz, côtes menuiseries)
- 📁 Documents par chantier (plans, devis, photos...)
- 🎤 Commandes vocales (quand déployé en HTTPS)

## Déploiement sur Vercel

1. Aller sur https://vercel.com
2. Se connecter (ou créer un compte gratuit)
3. Cliquer sur "Add New" > "Project"
4. Glisser-déposer ce dossier entier
5. Cliquer sur "Deploy"
6. L'app sera disponible sur une URL type: https://nord-bati-xxxxx.vercel.app

## Développement local

```bash
npm install
npm run dev
```

L'app sera disponible sur http://localhost:3000
